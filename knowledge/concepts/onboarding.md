# Onboarding

New members should:

1. Read the glossary Concepts in this repository.
2. Open a small Knowledge Change as a pull request.
3. Request review from at least one peer before merging.

Review decisions on GitHub are **Comment**, **Approve**, or **Request changes**.
They share the same review submission channel; the decision is the verdict attached to that review.
